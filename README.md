# One Emoji, One Smile

Entry for make.fun's "One Emoji, One Smile" bounty. The program writes
exactly one emoji — 🤗 (hugging face) — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

## Why 🤗

Against the judge's brief: open arms plus a big smile read instantly as a
warm welcome from a stranger; it needs no context or in-joke; it is a
deliberate pick rather than the default smiley; and it is warm without
intimacy, sarcasm or flirtation.
